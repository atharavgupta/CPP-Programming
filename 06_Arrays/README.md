# C++ Arrays

This folder contains C++ programs that demonstrate the use of arrays to store and process multiple values of the same data type.

These programs help build a strong understanding of array traversal, searching, reversing, and performing basic operations on array elements.

## Topics Covered

- Array declaration and initialization
- Accessing array elements
- Array traversal
- Searching in arrays
- Reversing an array
- Finding the smallest element
- Calculating sum and product of array elements
- Using loops with arrays

## Programs

| Program | Description |
| ----------------------------- | ----------------------------------------------------------- |
| `linear_search.cpp` | Searches for an element in an array using linear search. |
| `reverse_array.cpp` | Reverses the elements of an array. |
| `smallest_element.cpp` | Finds the smallest element present in an array. |
| `sum_product.cpp` | Calculates the sum and product of elements in an array. |

## Concepts Practiced

- Declaring and initializing arrays
- Accessing elements using indexes
- Traversing arrays using loops
- Performing searching operations
- Modifying and processing array elements
- Finding minimum values
- Performing arithmetic operations on arrays

## Tools Used

- C++
- Visual Studio Code
- GCC (MinGW)

## Purpose

The purpose of this folder is to strengthen understanding of arrays and their basic operations by solving different searching, traversal, and element-processing problems in C++.
