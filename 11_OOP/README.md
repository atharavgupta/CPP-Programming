# C++ Object-Oriented Programming (OOP)

This folder contains C++ programs that demonstrate the fundamental concepts of Object-Oriented Programming (OOP).

These programs help build an understanding of classes, objects, constructors, encapsulation, inheritance, function overloading, and polymorphism in C++.

## Topics Covered

- Classes and objects
- Constructors
- Encapsulation
- Function overloading
- Inheritance
- Compile-time polymorphism
- Runtime polymorphism
- Object-oriented programming principles

## Programs

| Program | Description |
| ----------------------------- | ----------------------------------------------------------- |
| `class_and_object.cpp` | Demonstrates the creation and use of classes and objects. |
| `constructor.cpp` | Demonstrates the use of constructors to initialize objects. |
| `encapsulation.cpp` | Demonstrates encapsulation by combining data and member functions within a class. |
| `function_overloading_polymorphism.cpp` | Demonstrates function overloading as an example of compile-time polymorphism. |
| `inheritance.cpp` | Demonstrates inheritance and how a derived class can acquire properties and behaviors of a base class. |
| `runtime_polymorphism.cpp` | Demonstrates runtime polymorphism using inheritance and function overriding. |

## Concepts Practiced

- Defining classes and creating objects
- Using constructors for object initialization
- Implementing encapsulation
- Understanding function overloading
- Implementing inheritance
- Understanding compile-time polymorphism
- Understanding runtime polymorphism
- Applying OOP concepts to C++ programs

## Tools Used

- C++
- Visual Studio Code
- GCC (MinGW)

## Purpose

The purpose of this folder is to strengthen understanding of Object-Oriented Programming concepts and their implementation in C++ through practical programs.
