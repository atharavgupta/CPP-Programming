# C++ Pattern Programs

This folder contains C++ programs that use loops and nested loops to print different patterns using characters and symbols.

These programs help improve logical thinking and understanding of loop execution.

## Topics Covered

* Pattern printing using loops
* Nested `for` loops
* Rows and columns
* Character-based patterns
* Pyramid and diamond patterns
* Controlling spaces and symbols using loops

## Programs

| Program                       | Description                                                 |
| ----------------------------- | ----------------------------------------------------------- |
| `character_patterns.cpp`      | Prints patterns using characters.                           |
| `hollow_diamond_patterns.cpp` | Prints hollow diamond patterns using loops and spaces.      |
| `pyramid_patterns.cpp`        | Prints pyramid-shaped patterns using loops.                 |
| `right_triangle_patterns.cpp` | Prints right-triangle patterns using characters or symbols. |

## Concepts Practiced

* Using nested loops to control rows and columns
* Printing spaces and symbols in a specific order
* Understanding how loop conditions affect pattern shapes
* Developing problem-solving and logical thinking skills

## Tools Used

* C++
* Visual Studio Code
* GCC (MinGW)

## Purpose

The purpose of this folder is to strengthen loop concepts and improve logical thinking by solving pattern-based programming problems in C++.
