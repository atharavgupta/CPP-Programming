# C++ If-Else

This folder contains C++ programs that demonstrate conditional statements and decision-making in programming.

These programs help build an understanding of how a program makes decisions based on conditions.

## Topics Covered

* `if` statement
* `if-else` statement
* `else-if` ladder
* Conditional expressions
* Decision-making using relational and logical operators

## Programs

| Program                      | Description                                                 |
| ---------------------------- | ----------------------------------------------------------- |
| `even_odd.cpp`               | Checks whether a number is even or odd.                     |
| `largest_of_two.cpp`         | Finds the larger of two numbers.                            |
| `leap_year.cpp`              | Checks whether a given year is a leap year.                 |
| `positive_negative_zero.cpp` | Determines whether a number is positive, negative, or zero. |

## Concepts Practiced

* Using conditions to control program flow
* Comparing values using relational operators
* Combining conditions using logical operators
* Implementing basic decision-making logic

## Tools Used

* C++
* Visual Studio Code
* GCC (MinGW)

## Purpose

The purpose of this folder is to practice conditional statements and develop logical thinking by solving simple decision-making problems in C++.
