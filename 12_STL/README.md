# C++ Standard Template Library (STL)

This folder contains C++ programs that demonstrate the use of commonly used components of the Standard Template Library (STL).

These programs help build an understanding of STL containers, pairs, iterators, and algorithms that are useful for writing efficient and reusable C++ programs.

## Topics Covered

- STL containers
- Vectors
- Pairs
- Stacks
- Queues
- Deques
- Lists
- Sets
- Maps
- Unordered maps
- Priority queues
- STL algorithms
- Common container operations

## Programs

| Program | Description |
| ----------------------------- | ----------------------------------------------------------- |
| `algorithms.cpp` | Demonstrates commonly used STL algorithms for performing operations on collections. |
| `deque.cpp` | Demonstrates the use and basic operations of the `deque` container. |
| `list.cpp` | Demonstrates the use and basic operations of the `list` container. |
| `map.cpp` | Demonstrates storing and accessing key-value pairs using the `map` container. |
| `pair.cpp` | Demonstrates the use of the `pair` data structure to store two related values. |
| `priority_queue.cpp` | Demonstrates the use of a priority queue for maintaining elements based on priority. |
| `queue.cpp` | Demonstrates the use and basic operations of the `queue` container. |
| `set.cpp` | Demonstrates the use of the `set` container for storing unique elements. |
| `stack.cpp` | Demonstrates the use and basic operations of the `stack` container. |
| `unordered_map.cpp` | Demonstrates storing key-value pairs using the `unordered_map` container. |
| `vectors_functions.cpp` | Demonstrates commonly used functions and operations with vectors. |

## Concepts Practiced

- Understanding STL and its components
- Using different STL containers
- Performing insertion, deletion, and access operations
- Working with key-value pairs
- Using stacks and queues
- Understanding ordered and unordered containers
- Using priority queues
- Working with STL algorithms
- Applying commonly used container functions

## Tools Used

- C++
- Visual Studio Code
- GCC (MinGW)

## Purpose

The purpose of this folder is to build familiarity with the C++ Standard Template Library (STL) and its commonly used containers and algorithms, which are important for efficient C++ programming and problem solving.
