# C++ Functions

This folder contains C++ programs that demonstrate the use of functions to make code reusable, organized, and modular.

These programs help improve understanding of how functions work and how they can be used to solve mathematical and logical problems.

## Topics Covered

- Function declaration and definition
- Function calling
- Parameters and arguments
- Return values
- Code reusability
- Passing values to functions
- Using functions for mathematical calculations

## Programs

| Program | Description |
| ----------------------------- | ----------------------------------------------------------- |
| `factorial_using_functions.cpp` | Calculates the factorial of a number using a function. |
| `fibonacci.cpp` | Generates Fibonacci numbers using a function. |
| `prime_till_n.cpp` | Prints all prime numbers up to a given number. |
| `sum_of_digits.cpp` | Calculates the sum of the digits of a number using a function. |

## Concepts Practiced

- Defining and calling functions
- Passing arguments to functions
- Returning values from functions
- Breaking problems into smaller tasks
- Reusing functions to avoid repetitive code
- Applying functions to mathematical and logical problems

## Tools Used

- C++
- Visual Studio Code
- GCC (MinGW)

## Purpose

The purpose of this folder is to strengthen understanding of functions and modular programming by solving mathematical and logical problems in C++.
