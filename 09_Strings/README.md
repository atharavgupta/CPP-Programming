# C++ Strings

This folder contains C++ programs that demonstrate the use of strings for storing, processing, and manipulating text.

These programs help build an understanding of common string operations such as counting characters, checking palindromes, removing occurrences, and reversing strings.

## Topics Covered

- String declaration and initialization
- Accessing string characters
- Traversing strings
- Counting vowels
- Checking palindromes
- Removing character occurrences
- Reversing a string
- Basic string manipulation

## Programs

| Program | Description |
| ----------------------------- | ----------------------------------------------------------- |
| `count_vowels.cpp` | Counts the number of vowels present in a string. |
| `palindrome.cpp` | Checks whether a string is a palindrome. |
| `remove_all_occurances.cpp` | Removes all occurrences of a specified character from a string. |
| `reverse_string.cpp` | Reverses the characters of a string. |

## Concepts Practiced

- Declaring and initializing strings
- Accessing individual characters
- Traversing strings using loops
- Comparing characters
- Modifying string contents
- Reversing strings
- Performing basic string manipulation

## Tools Used

- C++
- Visual Studio Code
- GCC (MinGW)

## Purpose

The purpose of this folder is to strengthen understanding of strings and their basic operations by solving different text-processing and string-manipulation problems in C++.
