# C++ Pointers

This folder contains C++ programs that demonstrate the use of pointers to access and manipulate data through memory addresses.

These programs help build an understanding of pointer concepts and how pointers can be used with variables and arrays to perform different operations.

## Topics Covered

- Pointer declaration and initialization
- Address and dereference operators
- Accessing values using pointers
- Modifying values using pointers
- Using pointers with arrays
- Finding the largest element using pointers
- Swapping values using pointers

## Programs

| Program | Description |
| ----------------------------- | ----------------------------------------------------------- |
| `array_using_pointers.cpp` | Demonstrates how pointers can be used to access and traverse array elements. |
| `largest_using_pointers.cpp` | Finds the largest element using pointers. |
| `modify_value_using_pointers.cpp` | Modifies the value of a variable using a pointer. |
| `swap_using_pointers.cpp` | Swaps two values using pointers. |

## Concepts Practiced

- Declaring and initializing pointers
- Using address (`&`) and dereference (`*`) operators
- Accessing and modifying values through pointers
- Pointer manipulation with arrays
- Passing addresses to perform operations
- Understanding memory addresses and references

## Tools Used

- C++
- Visual Studio Code
- GCC (MinGW)

## Purpose

The purpose of this folder is to strengthen understanding of pointers and memory addresses by implementing different operations using pointers in C++.
