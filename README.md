# C++ Programming

A structured C++ programming repository covering core programming concepts, Object-Oriented Programming (OOP), Standard Template Library (STL), and foundational problem-solving skills.

This repository was created to build a strong foundation in C++ through topic-wise programs and practical implementation of concepts.

## Topics Covered

- C++ Basics
- If-Else and Conditional Statements
- Loops
- Pattern Programming
- Functions
- Arrays
- Vectors
- Pointers
- Strings
- Structures
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)

## Repository Structure

| Folder | Topics Covered |
| ----------------------------- | ----------------------------------------------------------- |
| `01_Basics` | Basic syntax, input/output, data types, and type casting |
| `02_If_Else` | Conditional statements and decision-making |
| `03_Loops` | `for`, `while`, and loop-based problems |
| `04_Patterns` | Character, number, and geometric patterns |
| `05_Functions` | Function declaration, parameters, return values, and modular programming |
| `06_Arrays` | Array traversal, searching, reversing, and basic operations |
| `07_Vectors` | Dynamic arrays and basic vector operations |
| `08_Pointers` | Pointers, memory addresses, dereferencing, and pointer-based operations |
| `09_Strings` | String manipulation and text-processing problems |
| `10_Structures` | User-defined data types and structured records |
| `11_OOP` | Classes, objects, constructors, encapsulation, inheritance, and polymorphism |
| `12_STL` | STL containers, pairs, algorithms, and commonly used data structures |

The programs are organized topic-wise to make it easier to review concepts and track progress.
