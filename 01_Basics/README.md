# C++ Basics

This folder contains beginner-level C++ programs that introduce the fundamental concepts of the C++ programming language.

These programs helped me understand basic syntax, data types, input/output operations, and type conversion.

## Topics Covered

* Basic C++ program structure
* Output using `cout`
* User input using `cin`
* Data types and variables
* Type casting and type conversion

## Programs

| Program            | Description                                                |
| ------------------ | ---------------------------------------------------------- |
| `hello_world.cpp`  | Prints a basic "Hello, World!" message to the console.     |
| `user_input.cpp`   | Takes input from the user and displays the entered values. |
| `data_types.cpp`   | Demonstrates different C++ data types and variables.       |
| `type_casting.cpp` | Demonstrates type conversion and casting in C++.           |

## Concepts Practiced

* Basic program structure using `main()`
* Header files and the `iostream` library
* Variables and data types
* Standard input and output
* Type conversion

## Tools Used

* C++
* Visual Studio Code
* GCC (MinGW)

## Purpose

The purpose of this folder is to build a strong foundation in C++ by practicing simple programs and understanding the basic syntax and features of the language.
