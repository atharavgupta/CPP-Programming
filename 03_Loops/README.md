# C++ Loops

This folder contains C++ programs that demonstrate the use of loops for repetition and iteration.

These programs help develop an understanding of how loops execute repeatedly to solve problems involving numbers and mathematical operations.

## Topics Covered

* `for` loop
* `while` loop
* Loop initialization, condition, and update
* Nested and iterative logic
* Using loops for mathematical calculations

## Programs

| Program                  | Description                                                              |
| ------------------------ | ------------------------------------------------------------------------ |
| `factorial.cpp`          | Calculates the factorial of a given number using a loop.                 |
| `n_natural_numbers.cpp`  | Prints the first N natural numbers.                                      |
| `prime_number.cpp`       | Checks whether a given number is prime.                                  |
| `sum_divisible_by_3.cpp` | Calculates the sum of numbers divisible by 3 within the specified range. |

## Concepts Practiced

* Repeating instructions using loops
* Controlling loop execution with conditions
* Performing mathematical calculations through iteration
* Using conditional statements inside loops
* Developing logical thinking through number-based problems

## Tools Used

* C++
* Visual Studio Code
* GCC (MinGW)

## Purpose

The purpose of this folder is to strengthen programming fundamentals by practicing loops and using iteration to solve basic mathematical and logical problems.
