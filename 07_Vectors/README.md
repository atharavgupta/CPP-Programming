# C++ Vectors

This folder contains C++ programs that demonstrate the use of vectors, a dynamic array provided by the C++ Standard Template Library (STL).

These programs help build an understanding of vector operations such as searching, reversing, accessing elements, and performing calculations using vector elements.

## Topics Covered

- Vector declaration and initialization
- Dynamic storage using vectors
- Accessing vector elements
- Traversing vectors
- Searching in vectors
- Reversing a vector
- Finding the largest element
- Performing calculations using vectors

## Programs

| Program | Description |
| ----------------------------- | ----------------------------------------------------------- |
| `largest_element_vector.cpp` | Finds the largest element present in a vector. |
| `linear_search_vector.cpp` | Searches for an element in a vector using linear search. |
| `multiplication_table_vector.cpp` | Generates a multiplication table using a vector. |
| `reverse_vector.cpp` | Reverses the elements of a vector. |

## Concepts Practiced

- Declaring and initializing vectors
- Using the `vector` container
- Accessing elements using indexes
- Traversing vectors using loops
- Searching for elements
- Finding the maximum element
- Reversing vector elements
- Performing operations on dynamic collections

## Tools Used

- C++
- Visual Studio Code
- GCC (MinGW)

## Purpose

The purpose of this folder is to strengthen understanding of vectors and their basic operations while getting familiar with dynamic arrays and the C++ Standard Template Library (STL).
